# Conclusion

Policy-preserving edits to initially suboptimal punishment values alter finite-window shock responses in a learned public goods game on uniform hypergraphs. The fixed-design near-minus-far contrast is nonzero across 20 independent networks, but is below the prespecified relevance threshold and is strongly influenced by the far intervention's unshocked transient. Complete Q-freezing recovers the predicted pathwise equality, and local replays show how a decrease in a competing cooperation value can expose an unchanged punishment value as greedy.

The supporting controls narrow the conclusion. Matched-action results do not establish punishment specificity. Long high-cost histories fail the common-support requirements, while a separately calibrated short phase makes natural-gap transplantation feasible without producing a clearly nonzero effect at any assessed washout. Hidden action values therefore matter under the controlled construction studied here, but neither a general resilience benefit nor a robust natural-history effect has been established. Extending the same paired design to a separately selected operating point and expanding the prespecified onset sample would test the scope of this conclusion without changing the completed primary endpoint.
