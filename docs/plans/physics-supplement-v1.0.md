## 机制观测与理论边界

记录三个不同的事件时刻：首次被编辑P条目进入任一分支greedy集合、首次全状态policy分离、首次实际action分离。
前缀上限为1000 MCS；未观察到者保留删失标记，禁止按是否分歧选择样本。
日志只保存关键事件和在线统计，不保存所有事件的JSONL。

固定MCS采样分别记录当前公开策略不同的节点比例、任意状态行greedy集合不同的节点比例、
当前行P属于greedy集合的比例，以及实际P行动比例。它们不能混用。
与q、fP、P/D相遇量和福利的固定窗口变化共同呈现；按历史再按网络聚合。
离散采样占比不等于每节点首次激活时间分布，时间先后和相关不等于完整因果中介。

设两分支同一条目的差为Delta Q，第j次共同更新的target差为Delta T_j，则

```text
Delta Q_m = (1-eta)^m Delta Q_0
          + eta * sum_{j=1..m} (1-eta)^(m-j) Delta T_j
```

只有共同target时，才得到 `Delta Q_m=(1-eta)^m Delta Q_0`，本模型为 `0.2^m`。
首次policy分歧之前不一定满足共同target：两分支可能同时以P为最优，但最大Q值不同。
足够严格的停止时刻是任一被编辑P条目首次进入任一分支greedy集合；在此之前，可由初始只改非最优P、
共同事件与相同公开路径归纳得到相同非P值和row maxima。浮点闭式核验须给出容差。

单步激活的充分条件为：共同C值M，两分支P值为M-d_near与M-d_far，0<d_near<d_far；
一次C更新下降A，满足 `d_near < A < d_far` 且 `Q_D < M-d_near`，则near中的P唯一最优，far中的P非最优。
所有gap须使用事件当时的数值，不能无条件代入初始lambda倍数。

以上关系属于局部更新机制和一致性验证，不是独立宏观预测。
若扩展后仍不能解释群体响应，后续应检验独立网络上的固定窗口预测或针对触发路径的干预，
不以继续堆积首次事件案例代替机制解释。
