# E2 v1.1 固定设计

Owner：项目维护者。输入：sham工作点锁定、独立功效pilot及原协议；输出：确认性六分支数据与网络聚类区间。
主张：在本模型和窗口内，保持初始策略函数相同的P差距干预是否改变增量冲击损失。
范围：一个工作点及主冲击，不包含自然历史、机制特异性或泛化结论。

## 锁定

p00=(r=.55,alpha=.02,beta=.4)，N=1000、g=5、L=1600，delta=.30、T=5000。
eta=gamma=.8、epsilon=.02、lambda=.5/1/2；有/无冲击配对，保留负损失。
H=20个全新网络，B=2独立训练历史，K=10套独立未来；root seed=2026100106。
H=20由协议最低值决定，pilot未约束到更大的H；不声称bootstrap规划H均为20就是功效充分的独立证明。
pilot B1/K3与E2 B2/K10的差异、10网络方差不稳定性保留于解释。

每图两历史共享同一network seed，初始化和学习流独立，运行及分析均断言同图哈希相同、跨图不同。
确认性图/历史不使用旧pilot检查点；新网络哈希还应与pilot比较以排除意外重用。
在100000/200000/500000MCS依次检查原协议公开比例门槛，取第一个通过者。
隐藏诊断只输出，不用于E2检查点选择；全部失败及原因保留，不替换网络或增加样本。
每个达标历史的首套未来另跑完整5000MCS冻结六分支；有差异立即停止科学解释。

## 统计与缺失

theta=mean_network(mean_valid_history(mean_future(L_.5-L_2)))。
每历史缺少任意一个K响应是程序错误，整批不生成科学结论。
历史最长训练仍不达标：记为训练不合格；有至少一条合格历史的网络用可用历史均值，
完全无合格历史的网络不进入条件效应估计，绝不填零。报告实际有效H与每图有效B，
另报告两历史均合格的完整网络均值作敏感性描述。不自动补网络。
网络为bootstrap独立单位，固定seed=2026100107、10000次整簇重采样、百分位95%区间。
唯一主要比较为theta，其余lambda损失/福利和轨迹是描述性结果。
Delta_min=.02不变，分别报告是否偏离0及相对2个百分点的量级，不把统计显著当作达到实质意义。
若95%区间落在±.02内，报告该区间事实；未预设正式等效检验，不据此宣称一般等效。

## 预算、停止与验证

最大训练40×500000×1000=200亿；响应40×10×6×5000×1000=120亿；
完整冻结40×6×5000×1000=12亿，总上限332亿微更新，加每历史的32事件短审计。
若全部100000MCS达标，实际约172亿，4 workers预计约8–12分钟；按实际完成数报告耗时。
delta=.10次要冲击不包含本批预算，后续单独规划，不静默加入主比较。
不得根据确认性均值、显著性或p值提前停止、增加样本或改变参数。

owner：`training`负责共享网络种子和首个达标检查点；`run_confirmatory.py`负责图/历史调度和归档；
既有 `run_power_pilot.run_network`复用六分支与完整冻结响应；`analyze_confirmatory.py`负责原始轨迹复算和网络聚类。
验证：新训练选择测试、全套测试、两个历史共享图的真实smoke、预先固定脚本/内核哈希、实际原始结果复算。
配置及脚本在计算前归档，运行期间不修改对应源码。
