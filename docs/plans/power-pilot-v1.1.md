# v1.1 配对差异方差预实验

Owner：项目维护者。输入：sham验证后锁定的工作点及该点预定10个训练检查点；
输出：网络均值差的标准差、规划H、冻结负对照与完整配对轨迹。范围：功效预实验，不是E2。

前置条件：E0核对完成，30条sham验证结束，固定优先顺序选择首个过门槛点，保存工作点锁定文件。
工作点与delta必须在读取任何near/far结果前锁定。后续不能因为效应方向、大小或p值更改点或主冲击。

复用该点预定replicate 0..9的100000MCS检查点，只按原协议公开训练门槛决定纳入；
不按sham恢复时长、隐藏门槛或near/far结果继续筛选检查点。所有不达标者保留排除原因。
这与后续E2的公开检查点规则一致；工作点验证中的隐藏门槛只用于点的可用性评估。
确认性实验须重新生成全新网络和训练历史，不能把这10个网络并入E2。

每个检查点3套新冲击/未来流，root seed=2026100104；N=1000、T=5000、delta=.30，
lambda=.5/1/2×有/无冲击共6分支。每网络首套未来再执行完整5000MCS冻结Q的6分支，
要求同一冲击条件下所有lambda的每个快照指标逐位相同、theta=0，否则停止科学解释。
不跨网络共享随机流，同一网络内六分支共享事件带和冲击节点。
最大科学响应9亿次更新、冻结3亿次，总计12亿次；4 workers，预计约1分钟。

独立单位为网络。先对3套未来的theta取均值得D_h，再计算网络间样本标准差sD。
依照协议规划 H=max(20,ceil(((1.96+.84)*sD/.02)^2))；若超过预算不得启动E2。
同时报告网络bootstrap的sD分布及规划H范围，提示10网络估计不稳定。
本预实验B=1/K=3，拟定E2 B=2/K=10；不能分解网络/历史方差，不能把规划当成精确80%功效保证。
原协议Delta_min=.02和5000MCS有符号平均损失保留；不因观察到小效应而换主终点或扩样追显著。

保存：配置、脚本、源归档、初始checkpoint ID/哈希、网络哈希、每套冲击节点/流种子、
六分支全指标轨迹、冻结轨迹、逐网络差异和完整失败记录。程序失败则不得生成成功样本量结论。
