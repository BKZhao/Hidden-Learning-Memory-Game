# E4自然成本历史、洗脱与自然gap移植

Owner：项目维护者。输入：E2固定检查点及同图新成本历史；输出：自然来源、共同支持审计与冲击响应。
范围：E2后的探索性机制补充，不替换确认性终点。依赖：[E3结果](../e3-results.md)。

## 固定样本与历史

固定E2 network0..9/history0，低成本alpha=.02的100000 MCS训练检查点为来源和固定接收参照。
同一图上新独立初始化/训练100000 MCS，alpha_pre=.30，其余参数相同。
root seed=2026100120，4 CPU workers。高成本不做结果筛选，不追加网络。
恢复alpha=.02，两来源共享独立洗脱事件流，连续观察Twash=0/1000/10000；不在各时间重启。
低来源来自已筛选E2合作历史、高来源未同样筛选且随机历史不同：不能把差异直接称为成本历史的纯因果效应。
原始q/fP、策略一致性、全行贪婪构成和gap/访问诊断全部保存。

## 自然gap映射与共同支持

当前公开行动sigma、Q行状态s、完整贪婪集合精确分层。P严格非最优，gap>1e-10。
每个网络、来源、Twash、层的原始自然条目≥20；不靠复制满足此门槛。
接收参照始终为原E2检查点，按每层原gap、节点/行稳定排序，固定u=(rank+.5)/n。
低/高来源、三个Twash共用u；经验逆CDF选择实际观察过的gap，允许重复取值但报告独立来源行数。
写QP'=M_ref-gap_source，保持C/D及所有其他状态。相同gap采用原QP保持逐位sham。
两来源共同满足最终参数下Q包络、严格非最优、初始全状态policy不变才纳入；不剪裁、不重新排列u。
先完成全部洗脱时间，再取三个Twash合法接收行的交集。所有响应均使用此同一行集；
至少30且占全部3N行≥20%（N1000时即600行）才运行移植响应；否则整网络移植响应不执行。
仍报告各时点可行行数与失败层；不降低门槛、不按未来效果挑点。不同网络分别构造共同支持。
仅支持自然gap取值校准，不证明整个联合Q状态可自然生成；条件化后的移植不等同总体历史效应。
记录移植gap分位数、实际改写行数、L1/L2改写量；不要求两来源等剂量，因为gap差正是被检验因素。

## 固定响应与统计

输入审计完成后锁响应tasks和源码哈希，按同一网络的固定shock/event seeds执行；洗脱流与响应流独立。
每个合法网络×Twash：low/high/sham×有无冲击六臂；N1000，delta=.30，T5000，K1。
所有Twash和来源共用同一接收参照、冲击节点与未来事件带；sham逐位保留。
按网络、Twash升序的首个合法组做六臂5000 MCS完整Q冻结；所有轨迹应相同于相应sham。
原始历史另各做有/无冲击两臂（每组最多四臂），同网络同冲击seed和事件带；
公开配置不同使冲击节点不必相同。贡献者少于floor(.30N)时记该来源冲击不合法，不补节点或改delta。
原始历史比较属于描述性总路径差异，不能当受控记忆因果效应。报告与移植方向是否一致。

预定义L=mean(q_z0-q_z1)，theta_natural=L_low−L_high（不按gap大小重命名near/far）。
每个Twash按网络平均；同时报告各有无冲击绝对q、fP及福利，避免只解释差中差。
10000次网络bootstrap，seed=2026100121；跨Twash比较用同一网络重采样索引，报告theta_1000/10000−theta_0。
合法独立网络少于3只报告描述值，不给bootstrap区间。多个探索性终点不校正多重比较，不声称确认性显著或等效。
支持交集固定只能排除条目覆盖变化混杂；不消除来源分层选择、独立历史或网络位置混杂。

## 预算与验证

高成本训练1b，双来源连续洗脱0.2b，合法移植响应最多0.9b，原始历史响应最多0.6b，完整冻结0.03b，合计≤2.73b微更新。
复用已有算子和流水线，未通过policy/sham/参考-Numba冻结测试不得启动。源码运行期间固定，原产物不覆盖。
输入不足属于识别支持限制，不解释为无自然记忆，也不依据效应方向增样。
