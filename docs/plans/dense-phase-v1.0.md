# 密集相图固定设计

Owner：项目维护者。输入：E1目标规模相图、论文主张与当前计算性能；输出：密集参数网格、配对sham响应和论文相图。
范围：探索性参数景观，不改变E2主终点，不按隐藏Q干预效果选点。相关：[E1目标规模结果](../e1-scale-results.md)、[论文初稿设计](paper-draft.md)。

## 主张与用途

主要问题是公共参数如何划分高贡献/低贡献区域，以及锁定工作点位于相边界还是相内部。
支持问题是固定delta=.30冲击的增量损失是否集中在公共相边界附近。
该批不运行near/far干预，因此不能证明隐藏Q效应跨参数泛化；它只为主效应提供宏观相结构背景。

## 固定网格

- N=1000、g=5、L=1600；eta=gamma=.8、epsilon=.02、c=1。
- r={.55,.60,.65,.70,.75,.80,.85,.90,.95}。
- alpha={.02,.05,.08,.11,.15,.22,.30}。
- beta={.4,.8,1.2}；共189点。
- 每点2个独立网络/初始化/训练流，共378条训练；100000 MCS，末5000 MCS统计。
- root seed=2026100150，与既有E0--E4c不同；阶段编码E5仅用于确定性种子命名。
- 训练公开稳定门槛不变：末5000 MCS平均q>=.80，且q和fP与前一窗口差均<=.02。

## 响应与缺失

对训练稳定且至少有300个贡献者的检查点运行一套新未来事件流：无冲击与delta=.30冲击共享事件带，
响应5000 MCS。若无冲击均值相对训练尾部的q或fP漂移> .02，该重复的loss不进入相图。
每点loss为0--2个合格重复的均值；n=0留空并加斜线，n=1加点纹理，n=2为实色。
不填零、不插值、不平滑，不把单重复极值当成稳健相特征。

## 预算与停止

训练上限37.8b微更新；响应上限3.78b，总上限41.58b。16个worker，仅并行独立轨迹。
378条训练与所有预定合法响应全部结束后汇总；任何失败都保留并使批次非完整，不补点、不按结果追加重复。
运行期间冻结 `src/hidden_memory/`、三个密集相图脚本和配置；产物写入新目录，不覆盖E1。

## 图与解释边界

正文图按beta分三列，q、fP、sham loss分三行，星号标识既有主工作点。
q/fP使用两训练重复的均值；loss显示实际合格重复数。相图用于说明宏观状态空间和边界，
不能据此把E2一个工作点的near/far效应外推到整个网格。
