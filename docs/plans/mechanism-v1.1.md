# E3机制补充：固定比较与识别边界

Owner：项目维护者。输入：E2完整轨迹、固定检查点和独立审查；输出：时间分解、可匹配性、行动对照及局部学习日志。
范围：E2之后的机制探索；不替换确认性终点，不并入E2估计。

## 顺序与问题

1. 全20网络已有轨迹分解，报告q、fP、福利和惩罚支出；fC=q-fP。
   固定描述窗1–10、11–50、51–100、101–500、501–1000、1001–5000；主窗口仍为1–5000。
2. 所有40检查点的C/D匹配与自然支持审计，仅使用初始状态，不能看新响应选匹配。
3. 若可比，20网络、预定history0、K1新未来进行匹配P子集与C/D改写。
4. 固定network0..3/history0/future0重放局部日志；不得挑最大效应轨迹。
5. 随后执行成本历史、洗脱和自然gap移植，另写固定设计。

## 匹配对照

按当前策略sigma、Q行s、初始贪婪集合精确分层；同节点同行优先，余下按gap排序一对一匹配。
每对原gap相对差≤5%，每边条目数及分层数量完全相同。lambda仍为.5/1/2。
若总gap之和（亦即相同lambda下总L1剂量）相对差>1%，按当前总差方向删除差值最大的匹配对，
直到≤1%或无对；不增大卡尺、不改最优条目、不截断越界值。
每边至少30行才进行响应。低于全3N行20%仍标低覆盖；这种结果不能证明全量P干预的行动特异性。
同一比较重新运行匹配子集上的P，不拿E2全量P作不等剂量的对照。
自然支持由独立E1-shock批次p00的10份训练检查点建立，按同样状态/greedy分层的P值1–99百分位；
参照层少于50条记不可评估，不用E2响应补足参照。

响应root seed=2026100110，每个网络固定一套新冲击与事件带，所有比较共用。
每合法C或D比较有4个编辑分支×有/无冲击，共8臂；sham两臂共享。
T=5000、delta=.30、学习/收益参数与E2不变。记录全部匹配/不匹配网络，不因结果删点。
最多20×18×5000×1000=18亿次更新；首个按编号合法网络完整冻结，最多再0.9亿次。
每个对照的theta及P子集theta，以及两者的配对差，按网络平均与10000次网络bootstrap描述。
两类比较及各种窗口均为探索性；不能把未通过匹配或小样本零效应解释成P特异。

## 局部日志约束

使用E2已归档的事件seed和冲击节点，六臂重放，不新增选择样本。
参考执行前缀固定到首次策略函数分离和首次实际行动分离均出现，最长1000 MCS；
记录相关Q更新的旧值/新值/目标/奖励、P与竞争行动交叉、访问数。
在前缀结束同一事件处与Numba比较所有状态数组及event；六臂另重放1000 MCS。
此前缀停止规则在回放前写入运行config，不声称完整传播链或访问衰减规律。
同时保存预定快照与E2原始q/fP逐位对照，以保证观察器没有改变演化。
指数衰减只作为固定目标近似检验；目标发生变化后不声称.2^m是系统收敛规律。

独立reviewer提出上述顺序；计算仅CPU4 workers。新算子须经冻结与参考实现核验后才能批量运行。
