# E3：基线瞬态、行动匹配与分歧起点

Owner：项目维护者。输入：E2全量轨迹、40份固定检查点、独立E1训练参照；输出：探索性机制证据。
范围：E2之后的解释性补充，不替换确认性主终点，不并入E2置信区间。
依赖：[固定设计](plans/mechanism-v1.1.md)、[E2结果](e2-results.md)。

## 当前结论

E2仍支持预定配对终点的非零受控干预差异。E3进一步表明：

- 全量干预的配对损失差有很大一部分来自far无冲击分支的短暂下降。
- 等条目数、近似等改写量的P/D子集比较尚不支持P行动特异性；也不能据此声称等效或无效。
- 固定4网络、有/无冲击的8个分歧前缀中，首次策略函数分离均由C值下降触发：
  near的P值本步未更新，却成为最优行动。这支持一个明确的局部分歧路径，不等于完整中介机制。
- 自然成本历史、洗脱与自然gap移植尚未运行；自然历史证据仍缺失。

## 匹配支持与自然值范围

匹配只使用初始状态，按当前行动、Q行和完整贪婪集合精确分层；原gap逐对相差≤5%，
相同lambda下总L1改写量相差≤1%，同条目数，同一新冲击和事件带。

全40检查点：C只能匹配0–5行，未达到预定30行门槛，未执行响应；D能匹配730–862行。
实际响应固定20网络history0，每侧742–840行，约占全部3N行的24.7%–28.0%。
独立审查验证逐对gap相对差最大0.04999975，总L1相对差最大0.00637374。
匹配未控制全部节点拓扑位置、访问次数和更新年龄；结果仅适用于所选子集。

独立E1-shock的p00十份训练检查点作为自然P值参照，按同样状态/greedy分层取1–99百分位，
每层不足50条不评估。40份E2检查点可评估条目覆盖98.26%–99.61%的可编辑P行。
超出参照区间的比例按检查点等权平均：near 4.84%、sham 1.68%、far 13.83%。
这说明far改变了更多边缘P值；百分位越界不等于不可能自然出现，落在区间也不证明整个联合Q状态可自然生成。

可审计产物：[匹配审计](../artifacts/e3-gap-audit-20261001-v2/summary.json)、同目录 `matching.csv` 和逐检查点匹配行ID。

## 新P/D响应

20网络×history0×1套新未来；每网络10臂（P/D的near/far各有无冲击，加共享sham有无冲击）。
N=1000，T=5000，delta=.30，root seed=2026100110。首个网络另做10臂全程Q冻结。
全部20个网络成功，零失败；总计10.5亿次微更新，批量计算35.84秒，不含前期准备与后续分析。

| 探索性终点 | 网络均值 | 95%网络bootstrap区间 |
|---|---:|---:|
| 匹配P子集theta | 0.00071206 | [−0.00176836, 0.00348598] |
| 匹配D子集theta | −0.00269290 | [−0.00598235, 0.00057602] |
| P theta − D theta | 0.00340496 | [−0.00084972, 0.00752603] |

固定seed=2026100111，10000次整网络bootstrap；未做多重比较校正，均为探索性区间。
差值为0.3405个百分点，区间[−0.0850,0.7526]个百分点跨零。不能支持P特异性，不能宣称两类干预等效。
K=1、复用E2图/历史限制精度与独立性；P子集与E2全量干预不是相同处理，不能将效应大小差直接归因于行动身份。

## 首次分歧的有界回放

固定network0–3/history0/future0，沿用E2事件seed和冲击节点。
参考实现逐事件观察near/far，直到首次全状态策略函数分离和首次实际行动分离均被找到，最长1000 MCS。
仅改写行可能改变策略函数，首次分离前逐事件检查所有本步改写行，等价于检查全状态策略是否首次不同。
每个前缀结束后，以Numba独立重放同样长度，逐位比较Q、策略、群组计数、访问数、最后更新时间和event。
另独立重放完整六臂1000 MCS，每一个采样时点的q/fP均与E2原始轨迹逐位一致。

| 网络 | 无冲击：首次policy / action事件 | 有冲击：首次policy / action事件 |
|---|---:|---:|
| 0 | 42 / 296 | 0 / 115 |
| 1 | 74 / 578 | 6 / 196 |
| 2 | 36 / 310 | 1 / 265 |
| 3 | 58 / 609 | 8 / 101 |

事件索引从0开始，0代表第一次微更新后，不代表干预后立即改变policy；1000次事件为1 MCS；这些分歧均发生在第1 MCS内。
八个首次policy分离均为C更新下降，near中的P进入贪婪集合，far中的P仍非最优。
例如network0无冲击、节点301的P行：C由8.603078降至8.416452，
near P保持8.457229而成为最优；far P保持8.019681而仍非最优。
因此，这些已观察到的最早分歧不需要先访问并上调P值。

[回放汇总](../artifacts/e3-divergence-20261001-v2/summary.json)保存首次分歧的完整Q行、reward/target、访问与更新年龄信息；
逐网络 `prefix-z*.jsonl` 保存前缀内相关P更新/交叉事件。
观察止于分歧起点，不能推断总体激活时间分布、后续完整传播链、因果中介比例或按访问次数的指数衰减。
