# 模型与实现边界

用途：记录协议 v1.0 在阶段 A 的数学映射、owner 和补充实现约定。
范围：固定参数、线性收益、三行动、自我状态、异步更新。
Owner：项目维护者。输入：原始 Word 第二至六节；输出：可核验的函数与不变性。
相关：[计划](plans/stage-a.md)、[验收](verification.md)。

## 模型

固定编码 C=0、D=1、P=2，`Q[N,3,3]` 为 float64。
`r=R/g` 已归一化；`c=1`，默认 `eta=gamma=0.8`、`epsilon=0.02`。

对包含焦点**新行动**的群体计数 `(nC,nD,nP)`：

```text
piC = r*c*(nC+nP) - c
piD = r*c*(nC+nP) - beta*nP
piP = r*c*(nC+nP) - c - alpha*nD
```

焦点奖励取其所有参与群体的平均。Q 的下一状态是选择的行动 `a`：

```text
target = reward + gamma * max(Q_old[i,a,:])
Q_new[i,s,a] = Q_old[i,s,a] + eta*(target-Q_old[i,s,a])
```

`learner.step` 保存旧状态和旧目标，用候选计数计算奖励，随后只改一个 Q 条目，
最后更新公开策略和缓存计数。目标在 `s=a` 时同样使用旧 Q。
`visit_count` 记录实际选择次数；`last_update_event` 只在启用且学习率非零时更新，
以 0 开始的事件编号记录，未更新为 -1；`state.event` 指向下一个事件。

每个事件固定四个独立均匀数：节点、探索判定、探索行动、贪婪并列选择。
节点索引取 `floor(u*N)`，动作/并列索引类似；每个分支读取同一事件行。
随机输入与条件执行路径无关；事件带分块不改变输入序列。
贪婪集合按精确相等定义，集合中的行动按 C、D、P 顺序均匀抽样。
1 MCS 恰为 N 次有放回节点抽样。

## 可核验推导

加权投影令 `w_ij=m_ij/k_i`，去掉自身后 `sum_j w_ij=g-1`。
把每条超边中自身贡献拆出，再按共现次数合并其他节点，得到：

```text
reward_i = (r-1)*c*x_i
         + sum_j w_ij*(r*c*x_j - alpha*p_i*d_j - beta*d_i*p_j)
```

因此它与逐超边奖励相等，但不意味着模型具有不可约高阶效应。
交叉验证奖励绝对误差门槛为 `1e-10`。

群体内收益相加，公共收益为 `g*r*c*(nC+nP)`，贡献支出为 `c*(nC+nP)`，
执行成本和罚款各出现 `nP*nD` 次，故：

```text
W_h = (g*r-1)*c*(nC+nP) - (alpha+beta)*nP*nD
W = sum_h W_h/(g*L)
```

罚款不再分配。`snapshot` 同时输出 q、fC、fP、按超度加权的 qk、
全群体快照投入、P/D 相遇次数、惩罚成本、罚款损失与福利。
它们是策略快照，不是逐焦点更新的现实账户流水。

干预设 `M=max(Q_C,Q_D)`、`d=M-Q_P>1e-10`，改为 `Q'_P=M-lambda*d`。
`lambda>0` 保证 `Q'_P<M`；C/D 与最大值集合保留，故所有状态行的策略概率保留。
先枚举合法群体中**实际存在的行动**的收益界，再计算包含零初始化的 Q 包络。
只要任一 lambda 越界，所有分支都排除该行；不截断单个分支。
若浮点表示使新 P 值等于 M，也共同排除该行。
`lambda=1` 不重算 Q，保证逐位假处理。

冻结 Q 时，初始公开策略相同且所有状态行策略相同；在相同事件下选择相同行动。
归纳可得每个后续事件的策略相同，因而奖励与快照相同。
此结论允许冲击改变节点所在状态行，因三行均已匹配；仅冻结 P 列不满足该证明。

## 模块 owner 与依赖

| Owner | 输入 → 输出 | 依赖与边界 |
|---|---|---|
| `parameters` | 标量 → 已校验参数 | 无状态 |
| `hypergraph` | 网络尺寸/RNG 或超边 → 稀疏关联与连通图 | 不处理策略或收益 |
| `state` | 图/种子 → 状态；状态 → 独立深拷贝 | 保存数组，统一校验缓存 |
| `payoff` | 状态/候选行动/参数 → 奖励 | 双实现，无状态修改 |
| `events` | RNG/事件数 → 固定四槽事件带 | 不知道当前策略 |
| `learner` | 状态/参数/事件 → 原位更新与事件记录 | 学习语义 owner 和参考实现 |
| `accelerated` | 同一状态/参数/事件 → 编译执行一个 MCS | `learner` 的加速后端；同输入交叉验算，无 fastmath |
| `intervention` | 检查点/参数 → 共同可干预集合及独立分支 | 一次性修改 P 值；不学习 |
| `shock` | 检查点/比例/独立 RNG → 节点；节点 → 策略重置 | 不更新 Q、访问记录和时间 |
| `checkpoint` | 完整状态/流状态/诊断 → 带哈希的 NPZ | I/O 边界；拒绝覆盖、禁用 pickle |
| `runner` | 状态/事件带/冲击 → 六分支及配对损失 | 协调，不承载奖励公式 |
| `metrics` | 状态或轨迹 → 快照、恢复、稳定性 | 不作科学显著性推断 |
| `audit` | 小规模配置 → T06–T10/T12 实运行证据、过程日志 | 另提供顺序吞吐基准 |
| `config` / `cli` | 配置或参数 → 验证/命令执行 | 未锁定确认配置立即拒绝 |

## 观测与持久化约定

- 轨迹包含 `t=0` 快照，配对损失仅用 `t=1..T`。`L=mean(q_unshocked-q_shocked)`，
  `theta=L_0.5-L_2`，保留正负号。不同分支的各项轨迹均保存。
- 阶段 A 每 1 MCS 同时计算福利，频率高于协议允许的每 10 MCS。
- 恢复输入仅含 `t=1..T`；使用完整 50 点后向窗口，不补虚构冲击前数据。
  首个可判定点为 t=50。恢复和崩溃均用该平滑轨迹，持续 200 点后回填区间起点。
  协议未细定窗口初始化，此处是明确的实现约定；正式分析需做初始化敏感性检验。
- 崩溃使用严格 `<q0-0.20`，恢复使用 `>=q0-0.05`。未达持续期返回 `None`，
  右删失标志为真，另保留观测截止时间；不把截止时间冒充恢复。
- 移动均值直接按完整窗口高精度累加，避免累计和相减在阈值处引入消减误差；
  主状态与学习仍为 float64。
- 检查点保存网络、策略、Q、群体计数、访问/更新时间、事件编号、各随机流状态、参数、
  来源训练标识、稳定性诊断、UUID、数组哈希、参数/网络哈希及软件版本。
  没有 Git commit 时写 `null`，另记录源码 SHA-256；不伪造版本号。
- `events.jsonl` 保存小规模近/远冲击分支的所有事件；`audit.json` 保存第一处全状态策略概率
  分歧、实际行动分歧及当次更新目标。无分歧时使用 `null`。

## 阶段限制

当前提供可逐事件审查的 Python/NumPy 参考实现，以及经同输入对照的 Numba 顺序加速后端。
Numba 使用固定四槽事件带；不在内核中重新抽随机数，不改变时间单位。
归约顺序通过不同超度的 strided NumPy mean 对照测试；关闭 fastmath。
加速后端不创建逐事件日志对象，使用 `traces` 时必须选择 reference；不会静默丢弃日志。
验证包含百万次更新后的全状态逐位一致、冻结学习、事件带分块与跨进程缓存加载。
已提供独立进程的 E0/E1 批量调度、每 MCS 轨迹、预设训练检查点和 sham 筛选，
运行入口见 [experiments.md](experiments.md)。已增加共享图的独立训练历史与100000/200000/500000MCS首个公开达标检查点选择，
以及六分支确认性运行和网络聚类bootstrap。自然历史与policy不变gap移植由
`natural_intervention`、`natural_washout`及相关运行脚本实现；范围与结果见[E4c](e4c-results.md)。
独立预测模块尚未实现。
原文 PDF 已由用户提供；图形与模型核对见 [source-paper-check.md](source-paper-check.md)。
作者原始数值尚未取得，目视趋势一致不能替代精确数值复现。
自然支持已有分层经验值审计和独立校准/验证；早期审计中的 `null` 保留其当时含义。
来源取值有支持不证明整个联合Q状态自然可达，也不证明移植效应非零。
