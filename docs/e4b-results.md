# E4b同起点自然成本阶段：仍无可识别的移植支持

Owner：项目维护者。输入：同一批10个E2高合作检查点；输出：成本阶段轨迹、共同洗脱、支持审计和合法响应。
范围：[E4b事前固定修订](plans/paired-cost-history-v1.1.md)，在[原E4](e4-results.md)支持失败后单独开展，不合并为确认性结果。

## 同起点结果

low/high从完全相同状态克隆，共享10000 MCS事件带，仅成本阶段alpha分别为.02/.30。
10个网络全部完成。高成本分支在所有网络均降到低合作状态；随后恢复alpha=.02并洗脱10000 MCS仍未回到高合作。
这支持本次同起点成本阶段造成总状态演化差异，不能将其单独归因于隐藏Q，因为公开策略也发生了大幅变化。

成本阶段高分支网络平均曲线首次q<.5在107 MCS、首次q<.1在330 MCS；
单网络首次q<.5范围98–112 MCS。这些阈值是轨迹的事后描述，不是停止规则。
最后1000 MCS平均q：low 0.9915133，high 0.0134108。
[成本阶段图](../artifacts/e4b-paired-cost-history-20261001/analysis/cost-phase.png)阴影为10网络最小—最大范围，并非置信区间。

## 识别门槛与响应

10网络×3时间的单时点匹配和跨时间共同接收行仍均为0。
预定20条来源层支持及600条共同接收行门槛未通过，所以不执行自然gap移植响应。
不据此填零效应、不降低门槛、不自动缩短成本阶段继续寻找可用支持。

全部高来源不足300名贡献者，delta=.30冲击不合法。
仅运行低来源有/无冲击、高来源无冲击，共90臂，全部成功。
高来源损失、两来源theta和洗脱前后theta变化均为null；原始历史与受控移植方向一致性仍不可检验。
没有合法移植组，因此没有执行科学完整冻结组；新算子与真实CP短测的冻结验证通过。

## 验证与边界

历史阶段17.61秒，合法响应16.28秒；新增更新成本阶段0.2b+洗脱0.2b+响应0.45b=0.85b，低于1.93b预算。
40项测试通过；真实E2检查点的2 MCS成本/洗脱及全部10响应臂、冻结短测另存`artifacts/e4b-smoke-20261001`，不参与科学统计。
运行配置、源码和初始/成本结束/洗脱检查点均保存；运行时未修改仿真源码。

E4b消除了原E4的不同初始化，结论仍条件化于已选择的10个高合作起点；
共享随机数不是隐藏Q独立机制的证明，有限时域内持续分离也不证明长期双稳态。
两次支持失败限制了当前自然历史识别路线，尚未满足论文所需的自然差距受控响应验证。
后续应先重新审查识别设计，而非继续按响应方向调成本时长、放宽分层或追加样本。
